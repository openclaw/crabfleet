# Crabfleet

Crabfleet brings your remote computers into a native Mac app. Save VNC connections, search your desktops, and switch between open connections. Use **Share This Mac** to host your Mac, or Crabfleet Connect to host Linux and Windows desktops.

The Mac viewer provides Metal rendering, Quick Connect, full-screen controls, multiple warm sessions, saved passwords, and Wake-on-LAN. Shared desktops negotiate video, audio, cursors, clipboard, and optional file transfers. Ordinary VNC connections work without an account.

Optional sign-in adds private desktop discovery. The [browser companion](https://crabfleet.openclaw.ai/app/) opens your relay-enabled Mac and Linux shares without a native viewer. Each account sees only its own published computers. Windows hosting currently supports direct VNC only.
