# Crabfleet

Crabfleet is a remote desktop app for VNC. Connect to saved computers in the native Mac app, share your Mac, or host a Linux or Windows desktop with Crabfleet Connect.

The Mac viewer provides Metal rendering, Quick Connect, full-screen controls, multiple warm sessions, saved passwords, and Wake-on-LAN. Shared desktops negotiate video, audio, cursors, clipboard, and optional file transfers. Ordinary VNC connections work without an account.

An optional desktop backend provides device sign-in, private desktop discovery, and an authenticated browser VNC relay. Each person sees their own shared computers.

Start with the [quickstart](/quickstart/), then read the [Mac app guide](/macos-native-client/) or [Linux connector guide](/linux-connector/). Operators can use the [administration guide](/admin/) and [desktop API reference](/api/).
